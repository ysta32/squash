Squash is built to be used without the mouse. Press <kbd>?</kbd> in the app to see this list at any time.

## Command palette

Press <kbd>⌘</kbd> <kbd>K</kbd> (<kbd>Ctrl</kbd> <kbd>K</kbd> outside macOS) to jump to any bug by number or title, switch workspaces, export, change the theme, or open settings.

## In the markup editor

<kbd>A</kbd> arrow, <kbd>B</kbd> box, <kbd>P</kbd> pen, <kbd>N</kbd> numbered pin, <kbd>⌘</kbd> <kbd>Z</kbd> undo, <kbd>Esc</kbd> close. See [Markup](/docs/markup).

## Picking several bugs

<kbd>X</kbd> picks the selected bug, and <kbd>⌘</kbd>, <kbd>Ctrl</kbd> or <kbd>Shift</kbd>-click picks with the mouse. With bugs picked, a bar offers resolve, reopen, assign, and send to Claude Code (<kbd>C</kbd>).
